# BizPlay

**BizPlay** is a professional business management solution built for lounge and entertainment venues — track daily operations, manage live floor sessions, handle staff, and analyze financial performance in real time.

## ✨ Key Features

- **Live Operations Module** — Open/close shifts, manage stations and sessions in real time, track beverages, billing and receipts
- **Real-time Dashboard** — Track revenue, expenses, and profit at a glance
- **Easy Entry Logging** — Quickly record and review daily business activities
- **Bulk Entry** — Fill in an entire month of entries in one spreadsheet-style view
- **Team Management** — Manage employees, track working hours and advances
- **Secure Access** — Role-based permissions for owners, managers, and staff
- **Financial Reports** — Breakdown charts, trend lines and Excel export
- **In-App Updates** — Automatically checks for new versions and downloads them directly
